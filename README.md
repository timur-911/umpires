# UMPIR.ES

Справочник международных судей по настольному теннису: профили судей, бейджи
(White / Blue / Gold), страны и ассоциации, турниры, карта и графы связей.

Сайт — одна статическая страница (`index.html`), без сборки и без бэкенда.
Публикуется на GitHub Pages.

## Публикация

1. Файлы `index.html` и `.nojekyll` должны лежать в корне ветки `main`.
2. Settings → Pages → Build and deployment: Source = **Deploy from a branch**,
   Branch = **main**, папка = **/ (root)**.
3. Через 1–2 минуты сайт доступен по адресу
   `https://timur-911.github.io/umpires/`.

Файл `.nojekyll` отключает обработку Jekyll — нужен, чтобы GitHub отдавал
страницу как есть.

## Что работает на GitHub Pages, а что нет

Работает всё статическое: поиск по судьям, профили, страны, турниры, карта,
графы, переключение RU/EN, тёмная тема.

Не работает: добавление и подтверждение данных самими судьями, вход, загрузка
файлов и «Входящие». Эти функции используют `claude.use("db" | "user" |
"assets")` — базу данных, авторизацию и хранилище артефактов claude.ai. На
статическом хостинге таких API нет, и страница показывает подсказку открыть её
в Claude. Чтобы эти разделы заработали на своём домене, понадобится отдельный
бэкенд (например, Supabase или Firebase) и замена вызовов `claude.use(...)`.

## Внешние зависимости (подключаются с CDN)

- шрифты Google Fonts: Fira Sans Extra Condensed, Golos Text, JetBrains Mono
- d3 7.9.0, Observable Plot 0.6.16 (jsdelivr)

## Данные

Данные вшиты в `index.html` в виде объекта `DATA`: списки активных
международных судей, Blue/Gold Badge, участники Олимпийских и Паралимпийских
игр, турниры. Источники указаны в подвале соответствующих разделов.
